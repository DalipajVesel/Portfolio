# Hospital ICU Database

Extension of an existing hospital information system schema so it can also
support an intensive care unit. Sixteen tables were added and two changed:
ICU admissions, vital signs, clinical scores, interventions, devices, nurse
shifts and medication administration. Five lookup tables hold the vital
sign types, score types, interventions, device types and administration
routes.

Health Informatics course.

The deliverable is the ERD and the relational schema (.png and .dia, they
open with Dia) and Report.txt, which describes every new or changed table
with its columns and relationships and gives sample INSERTs for the lookup
tables. The schema given by the course is in previous-system/, and the extension is built on HIS_Relational_Martidis_2012.

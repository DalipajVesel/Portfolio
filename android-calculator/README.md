# Android Calculator

A calculator app that copies the stock EMUI calculator of my old Huawei P30.
Java with XML views. The keypad is a GridLayout where every key carries its
character in android:tag, and exp4j does the arithmetic.

Personal project.

## Build and run

The Calculator folder opens straight in Android Studio. I ran it on the
Medium Phone emulator with API 36. Min SDK 24, target 37.

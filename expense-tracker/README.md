# Expense Tracker

An expense tracker for Android. You type a name and an amount, and the app
adds the time and the street where you are from the device location. The
expenses are kept on the phone with Room, and the list can show the last day,
week, month or year, or dates you pick, with the total at the top.

Personal project.

## Build and run

The ExpenseTracker folder opens straight in Android Studio. I ran it on the
Medium Phone emulator with API 36. Min SDK 24, target 37.

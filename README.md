# Portfolio

My projects from the Computer Engineering degree at the University of West
Attica and a few personal ones. Every folder has its own README with how to
build and run it.

- [expense-tracker-api](expense-tracker-api): REST API in Spring Boot with PostgreSQL and JWT, and the Android app that uses it
- [expense-tracker](expense-tracker): Android expense tracker that keeps the expenses on the phone with Room
- [android-calculator](android-calculator): Android copy of the EMUI calculator of the Huawei P30
- [icu-3d-simulation](icu-3d-simulation): 3D intensive care room in the browser with Babylon.js, the scenarios are JSON files
- [java-rmi-distributed-system](java-rmi-distributed-system): theatre seat reservations over Java RMI with callbacks
- [java-rmi-hotel-reservation](java-rmi-hotel-reservation): hotel booking over Java RMI
- [rpc-distributed-system](rpc-distributed-system): socket client, proxy and ONC RPC server in C for vector operations
- [rpc-vector-statistics](rpc-vector-statistics): client and server in C with ONC RPC for statistics on a vector
- [openmp-parallel-systems](openmp-parallel-systems): OpenMP in C, a matrix check with reduction and a parallel multisort
- [cuda-parallel-systems](cuda-parallel-systems): CUDA kernels for matrix statistics and a covariance matrix
- [mini-c-compiler](mini-c-compiler): lexer and parser for a small C-like language with flex and bison
- [ir-search-engine](ir-search-engine): search engine over Wikipedia articles with Boolean, TF-IDF and BM25
- [bankruptcy-classification](bankruptcy-classification): eight classifiers that predict bankruptcy, with scikit-learn
- [cnn-cifar10](cnn-cifar10): convolutional network for CIFAR-10 in Keras
- [clustering](clustering): five clustering algorithms on Iris, Wine and Digits
- [csp-constraint-programming](csp-constraint-programming): eight constraint problems with OR-Tools
- [signal-processing-convolution](signal-processing-convolution): noise filtering with two FIR filters in NumPy
- [webgl-graphics](webgl-graphics): 3D scene in plain WebGL
- [hospital-icu-database](hospital-icu-database): database schema extension for an intensive care unit
- [motor-fault-detection](motor-fault-detection): op-amp circuit that finds bearing wear from vibrations, simulated in TINA-TI
- [ai-in-education](ai-in-education): group literature review on AI chatbots in universities

Most code comments and program messages are in Greek.
